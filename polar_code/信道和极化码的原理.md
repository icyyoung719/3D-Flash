## 信道
极化码：先信道合并，再信道分裂，译码时先解码好的bit，再解码剩余的bit
### 信道合并
N个Bit通过一个信道传输，相当于每个bit分别通过各自的信道传输，进行N次，每个信道都是相同且无记忆的

极化码的信道$W_N$是不可分的，N个输入，N个输出，相互影响，并不独立，由两个$W_{N/2}$构成。

### 二进制删除信道的极化
可靠性低的信道用于传输固定的bit（冻结比特），可靠性高的信道用于传输信息bit

比如，对N=8，我们有5个信息bit，3个冻结比特，那么可以用可靠性高的5个信道传输信息bit，可靠性低的3个信道传输冻结比特0

在译码时，同样使用串行译码，将可靠性低的信道的输出直接译为0，其余bit正常译码

## matlab仿真过程
### 编码
1. 构造G矩阵
2. 计算Z向量，存放计划结果
3. 根据Z向量对信道的可靠性排序得到C，确定冻结比特的位置
4. u_vector = message*C
5. codeword = u_vector*G

### 引入错误
1.根据删除概率alpha，将codeword中的部分bit置为-1，表示无法判断是0还是1
### 译码
1. 计算最底部结点的LLR（由y和信道本身的特点计算得到）（可以是似然比，也可以是对数似然比）
2. 冻结比特直接置为0，不用计算
3. 信息比特由codeword和已经得到的译码结果计算得到
