## SC译码算法
参考链接：[SC译码示例](https://marshallcomm.cn/2017/03/13/polar-code-6-sc-decoder/#sc%E8%AF%91%E7%A0%81%E7%A4%BA%E4%BE%8B)
### 总体流程
1. 译码分为两个部分，包括前N/2部分和后N/2部分
2. 两个部分没有本质区别，只不过使用的中间结点的LLR不同，因此分开
3. 译码第1或N/2+1个比特时，需要初始化其部分的LLR，如8个bit，则需要初始化7/2=4个基础LLR
4. 译码其他比特时，7-4=3=2^1+2^0，因此还需要两层循环计算其对应的其余3个间接LLR
5. 计算出所有所需LLR后，奇数比特使用$L_{left} = sign(L_1)*sign(L_2)*min(abs(L_1),abs(L_2))$；
偶数比特使用$L_{right} = (1 - 2*u)*L_1 + L_2$, u是先前译码出的奇数比特值
6. 译码偶数比特位后，还需要更新内部节点比特值

### 总结
SC译码算法以LLR为判决准则，对每一个比特进行硬判决，按比特序号从小到大的顺序依次判决译码。当码长趋近于无穷时，由于各个分裂信道接近完全极化（其信道容量或者为0或者为1），毎个消息比特都会获得正确的译码结果，可以在理论上使得极化码达到信道的对称容量$I(W)$。而且SC译码器的复杂度仅为$O(NlogN)$和码长呈近似线性的关系。

然而，在有限码长下，由于信道极化并不完全，依然会存在一些消息比特无法被正确译码。当前面$i-1$个消息比特的译码中发生错误之后，由于SC译码器在对后面的消息比特译码时需要用到之前的消息比特的估计值，这就会导致较为严重的错误传递。因此，对于有限码长的极化码，采用SC译码器往往不能达到理想的性能。

## SCL译码算法
参考链接：[SCL译码示例](https://marshallcomm.cn/2017/03/15/polar-code-7-scl-decoder/#scl%E8%AF%91%E7%A0%81%E7%A4%BA%E4%BE%8B)

针对SC译码算法的缺点，一个直接的改进方案是，增加每一层路径搜索后允许保留的候选路径数量，同时对搜索路径进行剪枝，从仅允许选择“最好的一条路径进行下一步扩展”改为“最大允许选择最好的$L$条路径进行下一步扩展”，其中$L>=1$。

参数$L$为搜索深度，当$L=1$时，SCL译码算法退化为SC译码算法；当$L>=2^K$时，SCL译码算法等价于最大似然译码
### 路径度量值
在SCL译码过程中，存在$L$条路径同时进行译码搜索，对于任意一条路径$l \in \{1, 2, \ldots, L\}$以及任意发送比特$u_i$ ($i \in \{1, 2, \ldots, N\}$)，其对应的路径度量值定义如下：
$$
P M_l^{(i)} \triangleq \sum_{j=1}^{i} \ln \left( 1 + \exp \left( - (1 - 2 \hat{u}_j [l]) \cdot L_N^{(j)} \right) \right)
$$
其中，
$$
L_N^{(j)} [l] = \ln \frac{W_N^{(i)}(y_1^N, \hat{u}_1^{i-1}[l]|0)}{W_N^{(i)}(y_1^N, \hat{u}_1^{i-1}[l]|1)}
$$

如果发送端所有信息比特在$\{0, 1\}$上均匀分布，那么对于任意两条不同路径$l_1, l_2 \in \{1, 2, \ldots, L\}$，当且仅当$PM_{l_1}^{(i)} > PM_{l_2}^{(i)}$成立时，有如下关系成立：

$$
W_N^{(i)} \left( y_1^N, \hat{u}_1^{i-1}[l_1] | \hat{u}_1^i[l_1] \right) < W_N^{(i)} \left( y_1^N, \hat{u}_1^{i-1}[l_2] | \hat{u}_1^i[l_2] \right)
$$

由上式可见，路径对应的转移概率越大，路径度量值越小。基于这种关系就完全可以在对数似然比上对$2L$条路径进行挑选。式（1）可以近似表示为

$$
PM_l^{(i)} \approx 
\begin{cases} 
PM_l^{(i-1)}, & if \ \hat{u}_i[l] = \delta \left( L_N^{(i)}[l] \right) \\
PM_l^{(i-1)} + \left| L_N^{(i)}[l] \right|, & if \ \hat{u}_i[l] \neq \delta \left( L_N^{(i)}[l] \right)
\end{cases}
$$

但考虑译码过程中包含了信息比特和冻结比特，因此上式可以改写为

$$
PM_l^{(i)} = 
\begin{cases} 
PM_l^{(i-1)}, & if \ u_i \ is \ information \ or \ frozen \ bit \ and \ \hat{u}_i[l] = \delta \left( L_N^{(i)}[l] \right) \\
PM_l^{(i-1)} + \left| L_N^{(i)}[l] \right|, & if \ u_i \ is \ information \ or \ frozen \ bit \ and \ \hat{u}_i[l] \neq \delta \left( L_N^{(i)}[l] \right) \\
+ \infty, & if \ u_i \ is \ frozen \ bit \ and \ incorrect \ value
\end{cases}
$$

其中$\delta(x) = \frac{1}{2}(1 - sign(x))$, $PM_l^{(0)} = 0$。对于信息比特的判决有

$$
\hat{u}_i = \delta \left( L_N^{(i)} \left( y_1^N, \hat{u}_1^{i-1} \right) \right)
$$
